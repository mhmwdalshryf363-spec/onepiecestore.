# One Piece Store

موقع ثابت (GitHub Pages). الصفحات: index, products, product, cart (قائمتي), contact, payment|shipping|delivery.

## إضافة منتج
أضف عنصراً في `products.json`:
{"id": 13, "name": "...", "category": "collectibles|caps|tshirts|mugs", "description": "...", "specs": ["..."], "image": "https://...", "link": "رابط الأفلييت", "store": "noon|amazon|aliexpress|jumia", "badge": ""}
- لا تضع رابطاً قبل الموافقة على حساب الأفلييت (يظهر "قريباً").
- الصور: فقط الصور التي يوفرها برنامج الأفلييت.
روابط التواصل في أعلى `app.js` (كائن SITE).
